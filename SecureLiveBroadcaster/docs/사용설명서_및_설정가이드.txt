================================================================================
     SecureLiveStream App (야외 고화질 라이브 송출 & OBS 원격 연동 가이드)
================================================================================

본 문서는 LTE/5G 환경의 스마트폰에서 Tailscale 사설망을 통해 집이나 작업실의
OBS PC로 초저지연·고화질(1080p FHD) SRT 라이브를 안전하게 송출하고,
OBS 원격 제어 및 치지직 채팅 TTS까지 완벽하게 세팅하는 통합 설명서입니다.

--------------------------------------------------------------------------------
[목 차]
1. 네트워크 기본 원리 (Tailscale)
2. 1단계: Tailscale 설치 및 IP 확인 (PC & 스마트폰)
3. 2단계: Windows 방화벽 규칙 추가 (SRT UDP 10000, OBS TCP 4455)
4. 3단계: OBS Studio 설정 (미디어 소스 & WebSocket 서버)
5. 4단계: 스마트폰 앱 설치 및 사용 방법
6. 5단계: 외장 카메라(액션캠 / 웹캠) C to C 직렬 연결 팁
7. 문제 해결 (FAQ & 트러블슈팅)

================================================================================
1. 네트워크 기본 원리 (Tailscale)
================================================================================
- 공인 IP나 공유기 포트포워딩 설정 없이, 전 세계 어디서든 나만의 안전한 가상 사설망
  (VPN)을 구축해 스마트폰과 송출 PC를 1:1로 암호화 터널링합니다.
- PC와 스마트폰 모두 Tailscale에 로그인하면 100.x.y.z 형태의 고유 IP가 부여되며,
  이 IP를 통해 집 안 공유기나 외부 LTE/5G 상관없이 다이렉트로 통신합니다.


================================================================================
2. 1단계: Tailscale 설치 및 IP 확인
================================================================================
1) 송출용 PC (Windows)
   - https://tailscale.com 접속하여 Windows용 Tailscale 다운로드 및 설치
   - 구글/애플/MS 계정 등으로 로그인
   - 윈도우 우측 하단 트레이 아이콘을 우클릭하여 PC에 할당된 100.x.y.z IP 확인
     (예: 100.72.172.45)

2) 스마트폰 (갤럭시 / 안드로이드)
   - Google Play 스토어에서 "Tailscale" 검색 후 설치
   - PC와 "동일한 계정"으로 로그인
   - 상단 스위치를 켜서 VPN 활성화 (상단 바에 열쇠/VPN 아이콘 확인)


================================================================================
3. 2단계: Windows 방화벽 규칙 추가 (필수 작업!)
================================================================================
외부 스마트폰에서 PC의 OBS로 들어오는 SRT 영상 신호(UDP)와 원격 제어 신호(TCP)를
Windows Defender 방화벽이 차단하지 않도록 인바운드 규칙을 열어주어야 합니다.

[방법 A: 파워셸(PowerShell) 관리자 권한으로 한 번에 적용하기 (권장!)]
1. Windows 시작 버튼 우클릭 -> [터미널(관리자)] 또는 [PowerShell(관리자)] 실행
2. 아래 2줄을 그대로 복사하여 붙여넣고 엔터(Enter)를 누릅니다:

New-NetFirewallRule -DisplayName "SecureLiveStream SRT (UDP 10000)" -Direction Inbound -LocalPort 10000 -Protocol UDP -Action Allow
New-NetFirewallRule -DisplayName "OBS WebSocket (TCP 4455)" -Direction Inbound -LocalPort 4455 -Protocol TCP -Action Allow

3. "경고 없이 정상 등록(True)" 문구가 나오면 방화벽 세팅이 즉시 완료됩니다.

[방법 B: Windows 방화벽 GUI에서 수동으로 추가하기]
1. 시작 메뉴에서 '고급 보안이 포함된 Windows Defender 방화벽' 검색 및 실행
2. 좌측 [인바운드 규칙] 클릭 -> 우측 [새 규칙...] 클릭
3. [포트] 선택 -> [다음]
   - 첫 번째 규칙: [UDP] 선택 -> 특정 로컬 포트에 10000 입력 -> [다음] -> [연결 허용] -> 이름에 "SecureLiveStream SRT" 입력 후 마침
   - 두 번째 규칙: [새 규칙...] -> [포트] -> [TCP] 선택 -> 특정 로컬 포트에 4455 입력 -> [다음] -> [연결 허용] -> 이름에 "OBS WebSocket" 입력 후 마침


================================================================================
4. 3단계: OBS Studio 설정
================================================================================

[A. 스마트폰 SRT 영상 수신 소스 추가]
1. OBS Studio를 실행합니다.
2. [소스 목록] 하단의 [+] 버튼 클릭 -> [미디어 소스] 선택 -> 이름 입력(예: 폰카메라)
3. 속성 창에서 반드시 다음 설정을 진행합니다:
   - [V] '로컬 파일' 체크박스 해제 (반드시 해제해야 네트워크 URL 입력란이 나옵니다!)
   - 입력 (Input):
     srt://100.x.y.z:10000?mode=listener&latency=2000000
     ※ 주의: 100.x.y.z 자리에는 내 PC의 Tailscale IP를 적습니다.
     ※ 패스프레이즈(암호)를 사용할 경우:
        srt://100.x.y.z:10000?mode=listener&latency=2000000&passphrase=내비밀번호
   - 입력 형식 (Input Format):
     mpegts
   - [ ] '표시되지 않을 때 파일 닫기' (또는 '표시되지 않을 때 재생 닫기') -> ★★★ 반드시 [체크 해제]! ★★★
     (※ 중요: 이 항목이 켜져 있으면, OBS에서 다른 장면으로 전환하거나 카메라 소스를 가렸을 때
      OBS가 네트워크 포트를 강제로 닫아버려 스마트폰의 SRT 송출이 즉시 끊어집니다!)
   - [ ] '소스가 활성화될 때 재생 다시 시작' -> [체크 해제] (실시간 라이브이므로 체크 해제 권장)
   - [V] '재생이 끝나면 재생 계속' -> 체크
   - 네트워크 버퍼링: 기본값 유지
4. [확인]을 누르면 스마트폰에서 송출이 시작되는 즉시 화면이 나타납니다.

[★ 핵심: OBS 장면 전환 시 100% 무중단 유지하는 꿀팁]
- 다른 장면(예: 대기화면, 채팅화면, 게임화면)에서도 카메라를 사용하거나 연결을 유지할 때:
  1) 새로운 미디어 소스를 만들지 마시고, 다른 장면에서 [+] -> [미디어 소스] -> [기존 소스 추가]를 눌러
     방금 생성한 '폰카메라'를 동일하게 불러오세요.
  2) 또는 [캠_전용] 장면을 하나 만들고 그 안에 미디어 소스를 넣은 뒤,
     다른 장면들에서 [+] -> [장면] -> [캠_전용]을 소스로 추가(중첩 장면)하면 장면 전환 시
     0.1초의 깜빡임도 없이 완벽하게 연속성을 유지합니다.

[B. OBS WebSocket v5 서버 활성화 (스마트폰 원격 제어용)]
1. OBS 상단 메뉴 [도구(Tools)] -> [WebSocket 서버 설정(WebSocket Server Settings)] 클릭
2. [V] 'WebSocket 서버 활성화' 체크
3. 서버 포트: 4455 (기본값)
4. [V] '인증 사용' 체크 -> [비밀번호 생성] 또는 기억하기 쉬운 비밀번호 입력 (예: obs1234)
5. [적용] 및 [확인] 클릭

5. 4단계: 스마트폰 앱 설치 및 사용 방법
================================================================================

[설치 방법]
1. 함께 제공된 `SecureLiveStreamingApp_Universal_Release.apk` 파일을 스마트폰으로 전송
   (카카오톡 나에게 보내기, 퀵쉐어, 구글 드라이브 등)
2. 스마트폰에서 해당 APK를 실행하여 설치
   - "보안상 알 수 없는 앱 설치 제한" 알림 시 -> [설정] -> [이 출처의 앱 허용] 활성화

[앱 실행 및 초기 세팅]
1. 스마트폰 상단바에서 Tailscale VPN이 켜져 있는지 확인합니다.
2. 앱을 실행하고 카메라, 마이크, 알림, 블루투스 권한을 허용합니다.
3. [좌측 제어 메뉴 숨기기/열기 (화면 가림 방지)]:
   - 좌측 상단의 [✕ 메뉴 닫기] 버튼이나 메뉴창 상단의 [✕ 닫기]를 누르면
     복잡한 설정창이 화면에서 완전히 숨겨져 카메라 프리뷰 시야가 시원하게 확보됩니다.
   - OBS 제어나 설정 변경이 필요할 때는 언제든 좌측 상단 [☰ 메뉴 열기]를 누르면 다시 나타납니다.
4. [SRT 송출 설정]:
   - 서버 URL: srt://100.x.y.z:10000  (내 PC Tailscale IP 및 포트 10000)
   - 스트림 ID: test (또는 비워둠)
   - 암호화 비밀번호: (10자 이상 권장, OBS와 일치해야 함)
   - [설정 저장] 터치 (AES 암호화되어 안전하게 자동 저장됨)
5. [OBS 원격 제어 및 장면/소스 조작]:
   - OBS PC IP: 100.x.y.z  (내 PC Tailscale IP)
   - 포트: 4455
   - 비밀번호: OBS에서 설정한 비밀번호
   - [OBS 연결] 터치 -> 녹색 "OBS: 연결됨" 상태 확인
     ※ 앱 화면에서 직접 OBS 방송 시작/종료를 원격 트리거할 수 있습니다.
   - [🎬 OBS 장면(Scene) 선택]: 드롭다운 메뉴를 터치하여 원하는 장면을 즉시 선택/전환.
   - [👁️ 소스 목록 On/Off 제어]: 현재 장면에 등록된 소스(카메라, 마이크, 이미지, 자막 등)의
     눈 모양 [👁️] 버튼을 눌러 실시간 숨김/표시 토글 가능.
   - [📺 송출 화면 모니터 (PiP)]:
     - 버튼을 누르면 우측 상단에 OBS의 최종 방송 화면이 16:9 미니 뷰로 뜹니다.
     - 초당 약 24 프레임(24 FPS)의 부드러운 실시간 모션으로 스트리밍되어 최종 화면을 매끄럽게 확인 가능합니다.
     - 다운로드 대역폭은 약 0.8~1.0 Mbps 수준에 불과하며, LTE/5G는 송신(업로드)과 수신(다운로드)이 독립적으로 분리되어 동작하므로 5Mbps 메인 카메라 SRT 업로드 품질에 전혀 지장을 주지 않습니다.
     - 네트워크 지연 시 프레임이 밀리거나 버퍼링되지 않도록 Ping-Pong 방식의 자동 백프레셔 제어가 적용되어 항상 최신 화면을 유지합니다.
     - 모니터 우측 상단의 [✕] 버튼이나 토글 버튼으로 언제든 켜고 끌 수 있습니다.
   - [⏱️ 치지직 송출 시간 실시간 타이머]:
     - 화면 상단 중앙 배지 및 OBS 설정란에 현재 OBS가 치지직으로 송출 중인 시간이 초 단위로 표시됩니다.
     - OBS 방송 시작 시 `🔴 치지직 LIVE 00:00:00`부터 자동으로 1초씩 카운트업되며, 방송 종료 시 총 방송 시간이 보존됩니다.
5. [📷 카메라 화면 모니터링 ON/OFF (OLED 절전 모드)]:
   - 우측 하단의 [👁️ 화면 ON] 버튼을 누르면 스마트폰의 카메라 프리뷰를 즉시 끕니다(`🚫 화면 OFF`).
   - 전면/후면 카메라, UVC 웹캠, 캡쳐보드 등 **어떤 카메라 모드에서도 메인 5Mbps SRT 방송은 1%의 끊김이나 지연 없이 100% 정상 송출**됩니다!
   - 야외 방송 시 화면 발열과 배터리 소모를 대폭 줄이고 OLED 번인을 방지할 수 있습니다.
   - 블랙 화면을 터치하거나 우측 하단 [👁️] 버튼을 누르면 즉시 카메라 모니터링 화면이 다시 켜집니다.
6. [치지직 채팅 TTS 설정 (선택사항)]:
   - 내 치지직 채널 ID(또는 채널명) 입력 후 [저장] -> [연결]
   - 시청자가 채팅을 치면 스마트폰 이어폰 또는 스피커로 TTS 음성이 자동 재생됩니다.
6-1. [치지직 방송 관리 (제목 및 태그 실시간 변경)]:
   - 좌측 메뉴 [■ 치지직 방송 관리]에서 [네이버 로그인] 버튼을 터치하여 공식 네이버 로그인 완료.
   - 로그인 즉시 현재 방송 제목과 태그가 자동으로 로드되며, 스마트폰에서 새 방송 제목과 태그를 입력하고 [방송 정보 적용]을 누르면 치지직 스튜디오에 즉각 실시간 반영됩니다!
7. [오디오 모드 선택]:
   - 블루투스(이어폰), 폰 내장(스피커폰), UVC 유선 중 원하는 오디오 입력 경로 선택.
8. [터치 잠금 (안전 기능)]:
   - 방송 중 실수로 화면이 눌리는 것을 방지하려면 우측 하단 [🔒] 버튼을 터치.
   - 해제할 때는 자물쇠 아이콘을 '5초간 길게' 누르면 잠금이 풀립니다.
9. [화면 꺼짐 및 잠금화면 방지 (자동 적용)]:
   - 폰 자체 설정(30초/1분 자동 꺼짐)과 무관하게, 앱이 켜져 있는 동안 화면이 꺼지거나
     잠금화면으로 넘어가지 않고 항상 켜진 상태를 유지합니다.
10. [방송 시작]:
   - [방송 시작] 버튼을 누르면 1080p FHD 5Mbps 고화질로 PC의 OBS로 실시간 전송됩니다!

6. 5단계: 외장 카메라(액션캠 / 웹캠) C to C 직렬 연결 팁
================================================================================
스마트폰 내장 렌즈 대신 고프로(GoPro), 인스타360, DJI 오즈모 액션, 외장 웹캠,
또는 HDMI 캡처카드를 연결하여 방송할 때의 가이드입니다.

1. 케이블 연결:
   - 데이터 전송을 지원하는 C to C 케이블로 스마트폰과 카메라를 직결합니다.
   - (단순 충전 전용 케이블은 인식이 되지 않으므로 데이터 케이블을 사용하세요.)
2. 액션캠 모드 선택 (매우 중요!):
   - 고프로, DJI, 인스타360 등은 USB 연결 시 화면에 모드 선택창이 뜹니다.
   - 반드시 **[웹캠(Webcam) 모드]** 또는 **[UVC 모드]**를 선택해야 합니다.
3. 앱에서 모드 전환:
   - 앱 화면 상단의 **[내장 카메라]** 버튼을 누르면 **[UVC 카메라]**로 모드가 전환됩니다.
   - 스마트폰 화면에 "USB 장치 액세스를 허용하시겠습니까?" 팝업이 뜨면 [확인] 터치.
4. 화질:
   - 앱 내 자동 협상 엔진이 하드웨어 센서의 1920x1080 규격을 감지하여 1:1 무손실
     고화질(5Mbps)로 송출합니다.

7. 문제 해결 (FAQ & 트러블슈팅)

Q1. OBS 미디어 소스에 화면이 안 뜨고 검은 화면만 나와요.
A1. 다음 3가지를 순서대로 점검하세요:
    1) Windows 방화벽에서 UDP 10000 포트가 허용되어 있는지 확인 (3단계 파워셸 명령어)
    2) OBS 미디어 소스 URL 뒤에 `?mode=listener&latency=2000000`가 붙어 있는지 확인
       (OBS가 먼저 리스너 상태로 대기하고 있어야 스마트폰이 접속할 수 있습니다.)
    3) PC와 스마트폰 모두 Tailscale VPN이 켜져 있고 같은 계정에 연결되었는지 확인

Q2. 스마트폰 앱에서 "OBS: 연결 실패"가 뜹니다.
A2. 1) Windows 방화벽에서 TCP 4455 포트가 열려 있는지 확인
    2) OBS 상단 메뉴 [도구] -> [WebSocket 서버 설정]에서 서버가 활성화되어 있는지 확인
    3) 입력한 비밀번호와 IP(100.x.y.z)가 정확한지 확인

Q3. 방송 화면에 모자이크가 생기거나 끊겨요.
A3. 1) LTE/5G 신호가 약한 장소인지 확인하세요.
    2) OBS 미디어 소스의 latency(지연시간) 옵션을 기본 2초(`latency=2000000`)로 설정하면
       네트워크 지터나 패킷 손실이 발생해도 끊김 없이 부드럽게 복구됩니다.

Q4. 다른 갤럭시 폰에서도 잘 되나요?
A4. 네! 본 앱은 구형 안드로이드 7.0부터 최신 안드로이드 14/15(Galaxy S, Z 폴드/플립,
    Note, A 시리즈 등) 전 기종을 지원하도록 범용 패키징(Universal Release)되어 있습니다.

Q5. OBS에서 웹소켓이나 마우스로 다른 장면(예: 대기화면, 채팅화면)으로 전환하면 스마트폰 SRT 연결이 끊어집니다!
A5. 100% OBS 미디어 소스의 "표시되지 않을 때 파일 닫기" 옵션 때문입니다!
    1) OBS에서 SRT 미디어 소스(예: 폰카메라)를 더블클릭(또는 우클릭 -> 속성)합니다.
    2) 속성 창 중간의 [표시되지 않을 때 파일 닫기] (Close file when inactive) 체크박스를 반드시 '해제'합니다.
    3) [소스가 활성화될 때 재생 다시 시작] (Restart playback when source becomes active) 체크박스도 '해제'합니다.
    4) [확인]을 누릅니다.
    이 설정을 끄면 OBS에서 어떤 다른 장면으로 넘어가도 백그라운드에서 SRT 수신 포트를 계속 열어두므로
    스마트폰 연결이 절대 끊어지지 않습니다!
    (※ 또한 앱 자체에도 2초 간격 15회 '자동 재연결(Auto-Reconnect)' 안전장치가 탑재되어 있어,
     혹시라도 일시적인 망 끊김이 발생하더라도 스마트폰을 터치할 필요 없이 자동으로 복구됩니다.)
